# Site Hydrothérapie Haute-Savoie

Site web pour Marie-Pierre Garnier, hydrothérapeute à Saint-Gingolph (Haute-Savoie).

## 🌐 Site en ligne

[Voir le site](https://marie-pierre-garnier-hydrotherapie.netlify.app)

## 🏗️ Technologies

- HTML5, CSS3, JavaScript vanilla
- [Decap CMS](https://decapcms.org/) pour la gestion de contenu
- [Netlify](https://www.netlify.com/) pour l'hébergement et l'authentification
- Responsive design avec animations
