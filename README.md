# Site Darshan - Centre de Bien-être et Hydrothérapie

Site web pour Darshan, centre de bien-être et d'hydrothérapie à Saint-Gingolph (Haute-Savoie).

## 🌐 Site en ligne

[Voir le site](https://centre-darshan.netlify.app)

## 🏗️ Technologies

- HTML5, CSS3, JavaScript vanilla
- [Decap CMS](https://decapcms.org/) pour la gestion de contenu
- [Netlify](https://www.netlify.com/) pour l'hébergement et l'authentification
- Responsive design avec animations
