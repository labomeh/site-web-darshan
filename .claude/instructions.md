# Instructions permanentes pour ce projet

## Design System
TOUJOURS se référer au fichier DESIGN_SYSTEM.md avant toute modification de code.

### Règles strictes :
1. **AVANT** toute modification de styles, couleurs, typographie ou layout :
    - Consulter DESIGN_SYSTEM.md
    - Vérifier que la modification est conforme
    - Si la modification nécessite un changement du design system, DEMANDER CONFIRMATION à l'utilisateur AVANT de modifier DESIGN_SYSTEM.md

2. **JAMAIS** modifier DESIGN_SYSTEM.md sans approbation explicite de l'utilisateur

3. **Validation systématique** :
    - Palette de couleurs respectée (vert sauge #8B9D83, beige doré #D4B896, etc.)
    - Typographie Roboto uniquement
    - Espacement basé sur le système 8px (4, 8, 16, 24, 32, 48, 64, 96px)
    - Contrastes WCAG AA minimum
    - Responsive sur les 3 breakpoints (640px, 1024px)

4. **Si un besoin sort du design system** :
    - Signaler l'écart à l'utilisateur
    - Proposer des alternatives conformes au design system
    - Attendre confirmation avant d'appliquer une solution non-conforme

## Ton et approche
- Site de bien-être : design doux, apaisant, professionnel
- Maximiser l'utilisation de l'espace (pas de vides inutiles)
- Images toujours accompagnées de texte
